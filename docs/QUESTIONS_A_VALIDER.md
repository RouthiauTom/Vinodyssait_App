# Cinq questions : corrections de format validées et appliquées

Les 673 questions sont conservées dans les sources et le brouillon. La banque structurée contient désormais les 673 questions. Les cinq corrections ci-dessous ont été validées par le porteur puis appliquées uniquement aux données dérivées. Les anomalies portent sur l’extraction de formats, pas sur des désaccords de réponses correctes identifiés.

| ID | Constat dans les sources | Proposition pour la copie dérivée |
| --- | --- | --- |
| 108 | La réponse FR/EN commence par `B` suivi de texte, sans deux-points. | Reconnaître explicitement B comme choix correct, sans changer la réponse affichée. |
| 166 | En anglais, le choix E est collé à la fin de la ligne D. FR contient A à E et la réponse FR/EN désigne D. | Séparer E de D dans les choix anglais ; conserver D comme réponse correcte. |
| 511 | En anglais, le choix D est collé à C. FR contient A à D et la réponse FR/EN désigne C. | Séparer D de C dans les choix anglais ; conserver C comme réponse correcte. |
| 532 | En français, le séparateur avant B contient des barres inverses sans `n`. EN contient A/B/C ; la réponse FR/EN désigne B. | Rétablir un saut de ligne avant B dans la copie dérivée ; conserver B comme réponse correcte. |
| 564 | Le choix B français est écrit `b` ; les autres lettres sont majuscules. La réponse FR/EN désigne B. | Reconnaître ce marqueur comme B dans les choix français ; conserver B comme réponse correcte. |

Ces cinq corrections proposées ne changent pas les contenus de réponse ni les explications. Elles sont validées et appliquées ; les CSV et le brouillon source sont inchangés. Aucune correction scientifique ou traduction libre n’est proposée ici. Les autres remarques éditoriales de l’audit, notamment la formulation de la question 2, demeurent distinctes.
